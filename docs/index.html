4つに共通するChainOSCらしさ

形は違っても、OSC設定を作り、再利用するための考え方は共通です。

1→N

1つのキーから複数メッセージ

Press／Releaseモードでは、押した時／離した時に合計8件までのOSCメッセージを設定でき、関連する複数の操作を1回のキー操作へまとめることが可能です。また、キーを押すたびに値を変化させるSequenceモードにも対応しています。

JSON

デバイスやアプリをまたぐプリセット

共通のKeyプリセットをM5ChainOSC、ChainOSCmini、ChainOSCnano、ChainOSC for Windowsで利用できます。操作する形を変えても、作り込んだOSC Address、型、値を持ち運べます。

4つのChainOSC

画面と拡張性、小型・超小型の専用機、追加ハードウェア不要。目的に合わせて選べます。

STANDARD HARDWARE

M5ChainOSC

画面付き・拡張性重視

AtomS3RとAtomic ToChain Baseで動作するスタンダード版です。画面で接続状態や送信内容を確認できます。

  • Chainデバイスを自由に組み合わせ
  • ブラウザーで設定
  • Web Installer対応
  • 本体画面で状態を確認
M5ChainOSCポータルGitHub
WINDOWS APP

ChainOSC for Windows

追加ハードウェア不要

WindowsのグローバルホットキーからOSCを送信するポータブルアプリです。タスクトレイに格納した状態でも動作します。

  • 任意の数のKey設定
  • グローバルホットキー
  • 日本語／英語UI
  • セットアップ不要のポータブル版
Windows版ポータルGitHub
COMPACT HARDWARE

ChainOSCmini

小型・2キー内蔵

Chain DualKey上で動作する小型版です。本体の2キーに加え、左右のChainポートへデバイスを接続できます。

  • 本体内蔵の2キー
  • 両側のChainポートに対応
  • ブラウザーで設定
  • Web Installer対応
ChainOSCminiポータルGitHub
NANO HARDWARE

ChainOSCnano

超小型・本体ボタン内蔵

M5NanoC6で動作する超小型版です。本体ボタンをKeyとして使いながら、Chainデバイスを接続できます。

  • 本体ボタンをKeyとして利用
  • 各種Chainデバイスに対応
  • ブラウザーで設定
  • Web Installer対応

どれを選ぶ？

複数種類の物理デバイスを使いたい画面で状態も確認できるM5ChainOSCがおすすめです。
追加ハードウェアなしで始めたいキーボードから操作できるChainOSC for Windowsがおすすめです。
小型の専用コントローラーが欲しい2キーを内蔵し、左右へ拡張できるChainOSCminiがおすすめです。
できるだけ小さく構成したいM5NanoC6の本体ボタンとChainデバイスを使えるChainOSCnanoがおすすめです。
