What makes ChainOSC a series

The form may change, but the approach to creating and reusing OSC settings remains consistent.

1→N

Multiple messages from one Key

In Press / Release mode, configure up to eight OSC messages across the two events and combine related actions into a single Key operation. Sequence mode is also available to change the transmitted value with each Key press.

JSON

Presets shared across devices and apps

Compatible Key presets work with M5ChainOSC, ChainOSCmini, and ChainOSC for Windows. Change the way you operate ChainOSC while carrying over your OSC Addresses, types, and values.

Three ways to use ChainOSC

Choose an on-device display and expandability, a compact dedicated controller, or a hardware-free Windows application.

STANDARD HARDWARE

M5ChainOSC

Display and expandability

The standard version runs on an AtomS3R with an Atomic ToChain Base. Its display provides status information.

  • Mix and match Chain devices
  • Browser-based configuration
  • Web Installer
  • On-device status display
M5ChainOSC portalGitHub
COMPACT HARDWARE

ChainOSCmini

Compact with two built-in Keys

The compact version runs on a Chain DualKey. Use its two built-in Keys and connect Chain devices to either side.

  • Two built-in Keys
  • Both Chain ports supported
  • Browser-based configuration
  • Web Installer
ChainOSCmini portalGitHub
WINDOWS APP

ChainOSC for Windows

No additional hardware

A portable Windows application that sends OSC from global hotkeys and continues operating from the system tray.

  • Any number of Key configurations
  • Global hotkeys
  • English and Japanese UI
  • No installation required
Windows portalGitHub

Which one should I choose?

I want several types of physical controlsChoose M5ChainOSC for its display and broad Chain-device support.
I want a compact dedicated controllerChoose ChainOSCmini for two built-in Keys and expansion on both sides.
I want to start without additional hardwareChoose ChainOSC for Windows to operate OSC from your keyboard.
